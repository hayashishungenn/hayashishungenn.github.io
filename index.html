openclaw

openclaw is a personal, non-commercial backup utility. It synchronizes the save files of single-player games from a private computer to the owner's own Google Drive, so that game progress is protected against disk failure and accidental deletion.

What this app does with your data

  • It only accesses the Google Drive storage of the app owner's own Google account.
  • It reads local game save files and uploads copies to a folder inside the owner's Drive.
  • It never collects, shares, or transfers any data to third parties.
  • It is used exclusively by its developer (single user) and is not distributed to the public.

Privacy Policy

This application does not collect, store, or process any personal data on any server. All synchronization happens directly between the owner's computer and the owner's own Google Drive. See the full Privacy Policy.
