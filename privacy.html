openclaw Privacy Policy

Last updated: 2026-10-09

1. Overview

openclaw is a personal, non-commercial backup utility operated by a single user (the developer). It copies local game save files from the developer's own computer to the developer's own Google Drive storage.

2. Data access

The application requests the Google Drive scope solely to read and write files inside the developer's own Google Drive. It does not access any other user's data, and it is not distributed to or usable by the public.

3. Data storage and sharing

No data is transmitted to any server other than Google's API endpoints. No data is sold, shared, or used for advertising. There are no analytics, tracking, or third-party services involved.

4. Data deletion

Backed-up files live only in the developer's own Google Drive and can be deleted there at any time. Revoking the application's access in Google Account permissions immediately removes its ability to access the Drive.
